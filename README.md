## About
Basically a visualizer for Bezier Curve using **De Casteljau's Algorithm**

![demo](demo.gif)

Inspired by [this video] by Freya Holmer(https://www.youtube.com/watch?v=aVwxzDHniEw&ab_channel=FreyaHolm%C3%A9r)

## Build
```console
npm i
npm run dev
open index.html
```
