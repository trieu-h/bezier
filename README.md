## About
A visualizer for Bezier Curve using **De Casteljau's Algorithm**

![demo](demo.gif)

Inspired by [this video](https://www.youtube.com/watch?v=aVwxzDHniEw&ab_channel=FreyaHolm%C3%A9r) by Freya Holmer

## Build

```console
npm i
npm run dev
open index.html
```
